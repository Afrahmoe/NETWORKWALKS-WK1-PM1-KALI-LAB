## Project Overview

This project involved setting up a virtual cybersecurity lab using Oracle VirtualBox and Kali Linux. The purpose was to prepare an isolated virtual environment for future cybersecurity and ethical hacking practical exercises.

## Lab Configuration

| Component | Configuration |
|---|---|
| Virtualization platform | Oracle VirtualBox |
| Virtual machine | Kali Linux |
| Network mode | NAT Network |
| Network subnet | `10.0.0.0/24` |
| Kali Linux IP address | `10.0.0.2/24` |
| Default gateway | `10.0.0.1` |
| DNS server | `10.0.0.1` |

## Tasks Completed

- Installed and configured VirtualBox.
- Created the NAT Network using the `10.0.0.0/24` subnet.
- Imported and configured the Kali Linux virtual machine.
- Assigned the required static IP address and network settings.
- Enabled the clipboard and drag-and-drop options.
- Configured the shared `/downloads` folder from the host machine.
- Checked internet connectivity.
- Created a snapshot of the virtual machine.
